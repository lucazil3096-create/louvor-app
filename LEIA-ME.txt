==========================================
  MINISTÉRIO AOS PÉS DA CRUZ - APP LETRAS
==========================================

COMO SUBIR PRO GITHUB PAGES:

1. Cria uma conta no GitHub (github.com)
2. Clica em "New Repository" (botão verde)
3. Nome: louvor-app (ou o que quiser)
4. Marca "Public"
5. Clica "Create repository"
6. Clica "uploading an existing file"
7. Arrasta TODOS os arquivos desta pasta (index.html + pasta pads/)
8. Clica "Commit changes"
9. Vai em Settings > Pages
10. Source: "Deploy from a branch"
11. Branch: main, /(root)
12. Clica Save
13. Espera ~2 min, o link aparece no topo!

COMO ADICIONAR MAIS PADS:

1. Renomeia o MP3 para "pad1.mp3" (ou pad2, pad3, pad4)
2. Coloca na pasta do tom correto:
   pads/C/pad1.mp3    (Dó)
   pads/Cs/pad1.mp3   (Dó#)
   pads/D/pad1.mp3    (Ré)
   pads/Ds/pad1.mp3   (Ré#)
   pads/E/pad1.mp3    (Mi)
   pads/F/pad1.mp3    (Fá)
   pads/Fs/pad1.mp3   (Fá#)
   pads/G/pad1.mp3    (Sol)
   pads/Gs/pad1.mp3   (Sol#)
   pads/A/pad1.mp3    (Lá)
   pads/As/pad1.mp3   (Lá#)
   pads/B/pad1.mp3    (Si)

3. IMPORTANTE: Edita o index.html e atualiza o PAD_MAP:
   Procura por "var PAD_MAP=" e adiciona os tons.
   Exemplo com C, D, G tendo 1 pad cada e E com 2 pads:
   
   var PAD_MAP={
   'C':[1],
   'D':[1],
   'E':[1,2],
   'G':[1]
   };

4. Sobe os arquivos novos pro GitHub

COMO ATIVAR NOTIFICAÇÕES PUSH (CELULAR):
==========================================

As notificações funcionam em 2 níveis:

NÍVEL 1 - NOTIFICAÇÕES LOCAIS (já funciona!):
- O usuário abre o Perfil e ativa "Receber notificações"
- Quando o app está em background (aba aberta mas não visível),
  recebe notificações de chat e mudanças na escala
- Funciona em Android (Chrome) e iPhone (Safari 16.4+ como PWA instalada)

NÍVEL 2 - PUSH REMOTO (app completamente fechado):
Requer deploy de Cloud Functions no Firebase (plano Blaze - pago por uso):

1. Instala o Firebase CLI:
   npm install -g firebase-tools

2. Faz login no Firebase:
   firebase login

3. Entra na pasta do projeto:
   cd louvor-app

4. Instala as dependências das Cloud Functions:
   cd functions && npm install && cd ..

5. Faz deploy das Cloud Functions:
   firebase deploy --only functions

6. (Opcional) Para gerar a VAPID key para push do navegador:
   - Acessa o console Firebase: https://console.firebase.google.com
   - Projeto louvor-app-a7264 > Cloud Messaging > Web Push certificates
   - Clica "Generate key pair"
   - Copia a chave e coloca no index.html onde tem "vapidKey:null"

7. Pronto! Agora push notifications funcionam mesmo com app fechado.

IMPORTANTE PARA iPHONE:
- O app DEVE ser instalado como PWA (Safari > Compartilhar > Adicionar à Tela de Início)
- Só funciona no iOS 16.4 ou superior
- Notificações NÃO funcionam no Safari normal, apenas na PWA instalada
